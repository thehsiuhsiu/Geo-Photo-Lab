# Geo-Photo-Lab（定點照片）

依手機當下 GPS 位置，顯示預先設定的定點參考照片（例如巡邏點現場照）的網頁工具。

- 網址：https://thehsiuhsiu.github.io/Geo-Photo-Lab/
- 所有資料只存在手機本機，不會上傳；可匯出以密碼加密的備份檔。
- 用語定義見 [GLOSSARY.md](GLOSSARY.md)，設計決策見 [docs/adr](docs/adr/)。

## iPhone 使用方式

1. 用 **Safari** 打開網址，按「分享」→「加入主畫面」。
2. **之後一律從主畫面圖示開啟**再新增定點。iPhone 上 Safari 分頁和主畫面 App 的資料是分開的，在 Safari 分頁裡加的定點，主畫面 App 看不到。
3. 第一次開啟時允許「定位」。
4. 定期按「備份」匯出備份檔，存到「檔案」App 或其他地方。
